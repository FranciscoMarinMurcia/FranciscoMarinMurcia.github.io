¿Cómo funciona este formulario?

Este formulario usa Formspree, un servicio que permite recibir por correo los datos de un formulario HTML sin necesidad de programar un servidor.

En la etiqueta form, el atributo action contiene el endpoint de Formspree (la dirección a la que se envían los datos) y method="POST" indica que los datos se envían de forma oculta, no en la URL.

Cada campo tiene un atributo name, que es el nombre con el que aparece el dato en el correo recibido. Además, se ha añadido un segundo destinatario (el profesor) desde el apartado Linked Emails de la cuenta de Formspree.
