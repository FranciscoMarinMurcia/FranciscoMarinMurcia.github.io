5 conceptos adquiridos en HTML

1. Etiquetas de texto

Las etiquetas de texto se utilizan para definir el contenido de un documento HTML.

ejemplo:

Encabezado de nivel 3

<h3>Encabezado de nivel 3</h3>

2. Listas

Las listas se utilizan para organizar información en una secuencia.

ejemplo:

  • Elemento 1
  • Elemento 2
  • Elemento 3
<ul>
  <li>Elemento 1</li>
  <li>Elemento 2</li>
  <li>Elemento 3</li>
</ul>

3. Imágenes

Las imágenes se utilizan para mostrar contenido visual en una página web.

ejemplo:


<img src="img_optimizadas/ejemplo_opt.jpg" alt="Imagen de ejemplo para la sección de conceptos" title="Imagen de ejemplo" width="100%" height="auto">

4. Tablas

Las tablas se utilizan para organizar datos en filas y columnas.

ejemplo:

Columna 1 Columna 2
Celda 1 Celda 2
<table>
  <tr>
    <th>Columna 1</th>
    <th>Columna 2</th>
  </tr>
  <tr>
    <td>Celda 1</td>
    <td>Celda 2</td>
  </tr>
</table>

5. Formularios

Los formularios se utilizan para recopilar información del usuario.

ejemplo:

<form action="submit.php" method="post">
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre" name="nombre">
  <input type="submit" value="Enviar">
</form>
